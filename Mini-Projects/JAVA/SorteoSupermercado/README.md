# 🛒 Sorteo Supermercado

Sistema de gestión y ejecución de sorteos automáticos para clientes de supermercados desarrollado en Java. Permite elegir mes y cantidad de ganadores, generar tickets de participación de forma transparente y seleccionar ganadores aleatorios.

---

## 🚀 Características

* **Asignación de oportunidades:** Generación automática de números de sorteo según el mes y cantidad de participantes.
* **Módulo de sorteo aleatorio:** Selección equitativa y transparente del ganador mediante algoritmo aleatorio.
* **Validación de comprobantes:** Control de duplicados para asegurar la validez de cada ticket registrado.

---

## 🛠️ Tecnologías y Herramientas

* **Lenguaje:** Java (versión 17 o superior recomendada)
* **Framework / Arquitectura:** [Swing ]
* **Gestor de dependencias:** [ant]


---

## 📋 Requisitos Previos

Asegúrate de contar con lo siguiente instalado en tu equipo:

* **JDK (Java Development Kit)** 17 o superior.
* **Apache Maven** o **Gradle** (si no utilizas el wrapper incluido).
* Un IDE de preferencia como **IntelliJ IDEA**, **Eclipse** o **NetBeans**.
