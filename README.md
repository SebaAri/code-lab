## 🚀 Áreas de estudio

### 💻 Programming

Proyectos y prácticas en distintos lenguajes de programación y tecnologías.

Incluye:

- Desarrollo web (HTML, CSS, JavaScript y Bootstrap).
- Programación orientada a objetos con Java.
- Scripts, algoritmos y lógica de programación.
- Bases de datos relacionales con MySQL.
- Organización y gestión de proyectos.

### 📊 Data Science

Material relacionado con análisis de datos y aprendizaje en ciencia de datos.

* Notebooks
* Ejercicios prácticos
* Exploración de datos

---

### 🌍 English

Recursos y práctica de inglés orientados al ámbito tecnológico.

Incluye:

* Lectura técnica
* Notas personales
* Vocabulario
